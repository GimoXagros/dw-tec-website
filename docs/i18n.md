# 한·영 콘텐츠 운영 안내

한국어는 기존 URL을 그대로 사용하고 영어는 같은 경로 앞에 `/en/`을 붙입니다. 예를 들어 `/company/history/`의 영어 대응 페이지는 `/en/company/history/`입니다. 브라우저 언어에 따른 강제 이동은 사용하지 않습니다.

## 콘텐츠와 경로

- 회사·사업·연혁·인증·수행 분야의 한·영 데이터: `src/data/company.ts`
- 공통 메뉴 문구: `src/i18n/messages/ko.ts`, `src/i18n/messages/en.ts`
- 한국어·영어 대응 경로: `src/i18n/routes.ts`
- 주요 발주처·협력사: `src/data/organizations.ts`
- 공통 페이지 본문: `src/components/pages/`
- 실제 URL을 만드는 얇은 페이지 파일: `src/pages/`, `src/pages/en/`

새 페이지를 만들 때에는 공통 페이지 컴포넌트가 `locale`을 받아 두 언어를 렌더링하게 하고, 한국어와 `/en/` 아래에 각각 얇은 wrapper를 추가합니다. 이어서 `routes.ts`, 헤더·푸터 메뉴, sitemap 및 Playwright 라우트 배열을 갱신합니다.

## 언어 선택과 검색 정보

헤더의 KOR/ENG 메뉴는 현재 페이지의 대응 경로를 일반 링크로 제공합니다. 각 페이지는 자신의 canonical을 가지며, 같은 콘텐츠의 `ko`, `en`, `x-default` 링크를 함께 제공합니다. `x-default`는 대응하는 한국어 URL입니다. 자바스크립트가 꺼져도 키보드 포커스로 언어 링크에 접근할 수 있습니다.

## 발주처·협력사와 로고

목록은 `organizations.ts`의 `displayOrder`로 관리합니다. 상호, 공식 홈페이지 주소, 공식 로고 출처와 공개 승인 여부를 확인한 항목만 추가합니다. 공식 영문명이 확인되지 않으면 임의 번역 대신 원래 상호를 `nameEn`에도 사용합니다.

타사 로고는 사용자의 명시적 요청에 따라 각 회사 공식 홈페이지에서 제공되는 공개 로고 원본을 사용합니다. 로고는 회사 식별과 공식 홈페이지 연결 용도로만 표시하며 변형하지 않습니다. 계약서, 승인서, 내부 출처 경로는 공개 데이터에 넣지 않습니다.

## 공개 전 확인

`npm run validate`를 실행해 두 언어의 경로, canonical·hreflang, 키보드 메뉴, 접근성, 내부 링크와 CNAME을 확인합니다. 공개 홈페이지에는 공종별 평가금액을 게시하지 않습니다. DNS와 메일 레코드는 이 콘텐츠 배포 절차에서 수정하지 않습니다.
