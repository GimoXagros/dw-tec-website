# 기업형 디자인 개편 진단

기준선: `21c9676f8f90f2df45cd16cc01ae56518931ba17` / 2026-09-02.
작업 브랜치: `codex/corporate-motion-refresh`.

## 현재 DW-TEC

- 유지할 장점: 검증된 회사 데이터, 4개 공종의 동등한 분류, 로컬 Pretendard, 정적 HTML, 명확한 연락처, 외부 추적·입력 폼 없는 구조, 독립적인 페이지 주소와 SEO.
- 약점: 좁고 균일한 흰 카드가 반복되어 지명원의 정보 배치를 그대로 읽는 인상이 강함. 사업의 전문성과 문의 동선보다 데이터의 나열이 먼저 보임.
- 정보 위계: 짧은 소개와 세부 수행 범위의 시각적 차이가 작고, 회사·사업 하위 메뉴를 찾으려면 페이지에 먼저 진입해야 함.
- 이미지: 공개 가능한 자사 사옥 이미지가 중심. 현장 사진을 임의 추가할 수 없으므로 사진을 반복하는 슬라이더가 아닌 단일 히어로를 유지.
- 인터랙션: 단순 색상 hover 위주. 메뉴 포커스 트랩과 스크롤 잠금은 추가 필요. 움직임은 접근을 지연시키지 않는 보조 수단으로만 사용.
- 반응형: 기존 360/768/1440 검사를 유지하고 390/1024/1920을 추가. 4열 카드의 기계적인 축소 대신 2열·1열 전환과 충분한 본문 너비 확보.
- 접근성·성능: 기준선 재검사 5개 테스트 통과, 검사 대상 Axe 위반 0. 첫 실행은 Astro preview 시작 방식 때문에 중단되어 서버가 준비된 뒤 동일 명령을 다시 실행함. 이 실패를 검사 통과로 취급하지 않음.

## 참고 사이트 관찰

외부 사이트는 렌더링 화면과 공개 메뉴 구조만 살펴보았으며 소스 코드·이미지·문구를 가져오지 않았다. 이후 사용자가 AI 이미지 활용을 허용해 단일 히어로를 가상 플랜트 콘셉트로 보완했다. 실제 본사 사진은 회사 소개에 유지하며 AI 표시·출처는 `visual-assets.md`에 기록한다.

- [무진기연](https://newmoojin.co.kr/): 밝은 헤더와 대형 사진, 사업 분류, 품질·지원·문의 영역이 이어짐. 사진 슬라이더와 카탈로그는 DW-TEC에 그대로 적용하지 않음.
- [한국플랜트서비스](https://www.hps.co.kr/): 회사 소개·큰 숫자·사업·지속가능경영 순서와 별도 문의 진입점을 확인. 첫 진입에 검은 화면이 보이는 구간은 채택하지 않음. 수치·인력·사업 사실은 참고하지 않음.
- [제이에스플랜트](https://www.ejsplant.com/): 사진 위 짧은 메시지, 사업 및 신뢰 정보 구분, 회사/사업 링크를 포함한 상세 푸터 확인. 로딩 오버레이·자동 슬라이드는 채택하지 않음.
- [한전KPS](https://www.kps.co.kr/web/index.do): 회사·사업·기술·품질·문의 등 분류가 명시된 탐색 구조를 공개 페이지에서 확인. 대규모 메뉴·기관용 정보 구조는 DW-TEC 규모에 맞춰 축소.
