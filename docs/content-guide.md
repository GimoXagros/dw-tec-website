`src/data/company.ts`를 열면 회사 정보와 사업 데이터가 한곳에 정리되어 있습니다. 문자열의 따옴표와 쉼표는 유지하고 내용만 바꾸세요. 저장 후 검사에서 오류가 나면 공개 배포가 중단됩니다.

| 항목                              | 데이터 이름 / 파일                       |

| 회사명·대표·주소·전화·팩스·이메일 | `company`                                |

대표전화 `054-783-9170`, 팩스 `054-783-9171`, 이메일 `dwtec@dw-tec.co.kr`는 중앙 데이터에서 변경합니다. 팩스는 전화 걸기 링크로 만들지 않습니다. 문의 페이지 소개 문구에 있는 대표전화도 함께 확인하세요.

## 날짜·면허

- 날짜는 `YYYY-MM-DD`, 연혁의 연도는 네 자리 숫자로 적습니다.
- 등록 예정과 등록 완료를 구분합니다. 전문소방시설공사업 등록일은 2026-08-26입니다.
- 공개 홈페이지에는 공종별 평가금액을 게시하지 않습니다. 필요한 경우 업무 목적을 확인한 뒤 별도 자료로 안내하세요.
- 특허결정과 특허등록은 다릅니다. 등록 증거 없이 “등록특허”로 바꾸지 마세요.
- 전기·소방 기술인력 등급은 해당 업종 경력수첩으로 확인합니다. 협회 간 등급을 혼용하지 않습니다.

## 사진

공개 가능한 로고·사옥 사진만 포함되어 있습니다. 새 사진은 ① 회사 사용권 ② 고객 공개 승인 ③ 시설 보안 ④ 얼굴·차량번호·명찰·도면·설비 식별정보를 점검한 뒤 사용하세요. 회사가 가지고 있다는 사실만으로 인터넷 공개 권한이 확인되는 것은 아닙니다.

1. 사진을 화면 크기에 맞춰 WebP 또는 AVIF로 변환합니다. 개인정보·위치 메타데이터를 제거합니다.
2. `public/images/`에 개인정보 없는 영문 파일명으로 넣습니다.
3. 해당 페이지의 `src`, 원본 비율에 맞는 `width`·`height`, 한국어 `alt`를 수정합니다.
4. 히어로를 제외한 사진에는 `loading="lazy"`를 사용합니다.
5. `srcset`과 `sizes`가 있으면 새 파일과 크기에 맞춰 함께 수정합니다.

로고는 비율을 유지합니다. 주요 발주처·협력사 로고는 각 회사 공식 홈페이지에서 제공되는 원본을 식별 목적으로 사용하며, 누르면 해당 공식 홈페이지가 새 창에서 열립니다. 파일과 링크 출처는 `src/data/organizations.ts`에서 함께 관리합니다. OES 공식 홈페이지는 현재 HTTP만 제공하므로 외부 이동 시 브라우저의 보안 표시가 달라질 수 있습니다. 공유 이미지는 `public/og/company.png`이며 1200×630입니다. 인증서·계약서 원본을 이미지로 공개하지 마세요.

## 새 실적과 자료실

현재 실적은 지명원 수행기록을 공개용 분야별 설명으로 요약했습니다. 발주처명·정확한 시설·금액·기간을 공개하려면 계약상 비밀유지와 발주처 공개 승인을 먼저 확인하세요. 소방 면허 취득 전 관련 작업을 전부 면허 취득 후의 독립 소방공사 실적으로 표시하지 마세요.

자료실은 승인된 공개 자료가 없어 숨겨져 있습니다. 가짜 다운로드나 “준비 중” 카드를 만들지 않습니다. PDF를 공개할 때에는 개인정보와 원본 문서 속성을 별도로 검사하고, 자동 검사 규칙의 예외는 검토를 거쳐 제한적으로 추가해야 합니다.

## 공개 전 확인

`npm run validate`와 `npm audit`를 실행하고 360·768·1440px 화면을 확인합니다. 테스트 성공만으로 내용의 사실성·법률·보안이 보장되지는 않습니다. 연락처, 최신 면허, 인증 유효기간, 자료 사용권은 담당자가 재확인하세요. `local-only/`와 원본 자료는 GitHub에 올리지 마세요.
