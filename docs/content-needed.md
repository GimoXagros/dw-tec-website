# 향후 사진 보완 요청

현재 개편은 기존 본사 외관·로고, 자체 기술선 그래픽 및 사용자가 허용한 AI 플랜트 콘셉트 이미지를 사용한다. AI 이미지는 첫 화면의 기업 소개용이며, 사용자의 후속 요청에 따라 화면의 설명 문구는 제거했다. 실제 작업사진을 대체하지 않는다. 추가 현장 사진이 없어도 레이아웃·정보·문의 동선은 완결되도록 구성한다.

| 필요한 자료                | 권장 구도                                                | 공개 전 확인                                 |
| -------------------------- | -------------------------------------------------------- | -------------------------------------------- |
| 사옥·공장 외관의 다른 시점 | 가로 16:9, 최소 2400px, 간판과 건물 전체, 여유 있는 하늘 | 직원 얼굴·차량번호·출입 정보 제외            |
| 전기공사 작업              | 작업자보다 케이블 가공·공구와 손 중심, 가로              | 설비번호·계통표지·도면·발전소 식별 단서 제외 |
| 기계설비 제작·설치         | 자사 공장 내 가공 장면, 작업물 중심                      | 고객명·제품 도면·명판·계약상 비밀 제외       |
| 비계 시공                  | 일반 공개 가능한 시설의 구조·안전 작업 중심              | 원전 배치·보안구역·접근 경로 노출 제외       |
| 소방설비 작업              | 감지기·배관 등 작업 디테일                               | 구역 표지·방호체 위치·시설명 제외            |

모든 사진은 원본 제공과 함께 촬영자/권리자의 회사 홈페이지 공개 허가, 현장·발주처의 인터넷 공개 승인 범위를 확인해야 한다. 지명원 사용 승인을 인터넷 전체 공개 승인으로 간주하지 않는다. 확인 전 현장 사진을 추가하지 않으며, 실제 시공 사진을 AI 이미지로 대체하지 않는다.
