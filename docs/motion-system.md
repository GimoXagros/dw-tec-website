# DW-TEC 모션·내비게이션 시스템

## 구현 원칙

CSS transition/keyframes와 기본 IntersectionObserver만 사용한다. 새 런타임 의존성은 없다. 사진 슬라이더, 강제 스크롤, 패럴랙스, 영상·음성, 로딩 화면, 무한 반복 효과는 사용하지 않는다.

공통 색·서체·간격·컨테이너·헤더·모션·계층 토큰은 `src/styles/global.css`의 단일 `:root`에 있다. `corporate.css`는 홈페이지 배치만, `motion.css`는 공통 동작만 담당한다. 로컬 Pretendard와 기존 회사 데이터는 유지한다.

## API

- `data-reveal="up"`: 본문·패널의 짧은 위쪽 이동 및 등장
- `data-reveal="line"`: 연혁·데이터 보드의 작은 이동
- `data-reveal="image"`: 이미지 영역에 같은 등장 규칙 적용
- `data-reveal="fade"`: 위치 이동 없는 등장용 확장점
- `data-reveal-delay="70"`: 지연 시간, 0–210ms 제한
- `data-reveal-group`: 자식의 70ms 간격 순차 등장

기본 hover/focus 180ms, 본문 리빌 520ms, 히어로 사진 1.045배 → 1배 1,200ms. 페이지 제목 진입 450ms. 모바일에서는 이동량과 제목 효과 시간을 줄인다. 반복 카운터는 도입하지 않았으며 모든 수치가 초기 HTML에 최종값으로 들어 있다.

## 초기화·실패 복구

`initMotion()`과 `initNavigation()`은 이전 observer·listener를 정리하고 재초기화한다. 일반 페이지 진입과 `astro:page-load`에서 실행할 수 있다. 재실행 검사는 중복 메뉴 이벤트와 sentinel 중복을 확인한다.

HTML/CSS 기본값은 **보이는 상태**다. observer 생성 성공 후 화면 아래의 요소에만 `reveal-pending`을 붙인다. 요소가 보이면 observer를 해제한다. 포커스가 진입한 요소는 즉시 표시한다. 예외 또는 observer가 첫 알림조차 보내지 않는 경우에는 4.5초 안전 타이머로 모든 숨김 상태를 해제한다. 첫 알림이 정상 도착하면 타이머를 해제하므로 첫 화면을 오래 읽은 뒤에도 아래 섹션의 등장 효과가 유지된다. 지원하지 않는 환경에서는 내용을 바로 보여준다.

숨김 탭에서 계속 도는 타이머나 애니메이션 루프는 없다. 한 번만 동작하는 안전 타이머만 사용한다. 수치 카운트업·상시 스크롤 핸들러·대형 애니메이션 라이브러리는 없다.

## 움직임 감소

`prefers-reduced-motion: reduce`에서는 모든 등장 요소의 opacity 1/transform none, 애니메이션 및 전환 없음, 최종 숫자 그대로 표시. 실행 중 설정이 바뀌어도 숨김 상태를 해제한다. 콘텐츠·배치는 달라지지 않는다.

## 메뉴

밝은 헤더로 원본 로고 가독성을 보존한다. viewport 상단의 작은 sentinel을 관찰해 헤더를 축소하며 본문 위치는 고정된 상단 여백으로 유지한다. 데스크톱 하위 메뉴는 hover·focus·버튼·Escape를 지원한다.

1023px 이하에서는 전체 메뉴, 배경 스크롤 잠금, 배경 inert, 버튼↔마지막 링크 포커스 트랩, Escape/링크 선택 시 닫기, Escape 후 버튼 포커스 복귀를 제공한다. JS 비활성 시에는 메뉴를 일반 문서 흐름에 노출하며 주요 링크와 하위 링크를 모두 사용할 수 있다.

## 페이지 전환

Astro ClientRouter는 추가하지 않았다. 이 사이트는 정적 회사 정보 탐색이 중심이므로 기존 MPA의 URL·SEO·포커스·뒤로/앞으로 이동을 보존한다. 시각적 일관성은 공통 제목 진입 효과로 충족한다. 라이브러리 추가·버전 변경 없음.

## 검증·향후 확장

새 본문에 필요한 `data-reveal`만 지정하고 개인정보·404에는 적용하지 않는다. 본문·링크는 서버 HTML에 먼저 둔다. 중요 정보를 hover 또는 JS에만 숨기지 않는다. 금액·연도 등 사실 데이터는 공통 데이터에서 읽는다.

자동 검사: 6개 화면 폭의 전체 13개 페이지, 이미지·링크·Axe, 메뉴 키보드/트랩/스크롤 잠금, observer 실패, 재초기화, 줄바꿈/overflow, JS 비활성, reduced-motion, MPA 앞뒤 이동. Axe는 실제 스크롤로 요소를 표시하고 애니메이션이 끝난 상태에서 수행한다. 시간 기반 효과를 강제로 끄거나 대비 기준을 낮추지 않는다.
